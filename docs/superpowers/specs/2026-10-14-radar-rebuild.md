# WAMO market radar rebuild

User intent: a dependable daily KR/US dashboard with 52-week near highs and industry action, separately from notable movers. User authorizes autonomous repair, alternative data paths, and deployment of the existing GitHub Pages site.

## Experience
Create radar.html as the main landing experience. Tabs: 52주 신고가권, 인더스트리 액션, 특징주. Default near-high distance is <=10%, with 0/5/10/15 controls. Show actual session date, close, daily/5-day return, relative volume, RS, industry, distance from 52-week intraday high. Include gainers and losers regardless of near-high membership. Industry action uses several constituents, near-high share, median 5-day return, advancing share, volume confirmation, and actual member links. Require at least three distinct symbols and two advancing members for a confirmed group; do not call one-stock groups industry action. State screened-universe scope, not whole-market breadth. Preserve old detail pages via ?stock=... and ?legacy=1.

User clarification: show near-high candidates and actual same-day new highs as separate selectable views. Add intradayHigh52 and closeHigh52 to stock objects (strictly above previous 251 observations, not ties), and newHighCount to industry groups.

## Data contract
New wamo_insights.py build_insights(payloads, now, previous=None) produces wamo_insights.json and an inline fallback in radar.html. Root schemaVersion=1, generatedAt, markets {KR,US}. Each market: asOf, expectedSession, status CURRENT/PARTIAL/STALE/UNAVAILABLE, nextScheduledFor, source, coverage {total,valid,excluded,eligible52w}, stocks [], industries [], movers [], warnings[]. A stock: id, symbol, ticker, name, market, industry, industrySource, asOf, close, changePct, return5d, return20d, high52, highDistancePct (nonnegative), volumeRatio (today / prior 50 sessions), rs, stage2, source, detailUrl, chartUrl, sparkline numeric[], catalysts [{date,title,url}], moverReasons string[]. Unknown numbers are null, never zero. industry: id,name,memberCount,nearHighCount,nearHighPct,advancingCount,advancingPct,medianReturn5d,medianChangePct,volumeConfirmedCount,confirmed,leaders [stock ids],members [stock ids]. Every stock data date equals its market asOf; exclude corrupt histories and stale individual quotes. At least 252 observations required for 52-week classification. For each market validate OHLCV and identity, keep prior verified market if replacement invalid, never advance asOf without new prices. Session is exchange-calendar aware. Industry fallback is industry/industryEn, then sector; mark broad grouping. Catalysts retain authentic URLs and dates and never assert causation.

## Reliability
Current price pipelines already use independent Yahoo/Nasdaq/Naver paths; verify live paths and repair evidence-backed gaps. Optional SEC/DART/metadata failure must not block daily price/radar display. Add universe fallback where upstream discovery is a single point of failure. Split quote freshness from metadata warning. Persist last good data; HTTP errors, invalid JSON, network timeout and stale responses must not erase rendered content. No 3-hour heartbeat expiry for still-valid last-close prices. Use next exchange close deadline to label stale. Build insight snapshot without network from verified local payload; collect optional news separately if supported. Atomic writes and one serial publish. Reuse existing schedules, no parallel writer races.

## Verification
Tests: 10% boundary vs real new high; stale/malformed/partial stocks; <252-day IPO; same-date industry membership and no lone-stock action; movers include downside outside highs; provider failures with fallback; retry interruption and snapshot preservation; mobile/desktop UI, filters, detail links, failed refresh retention; existing regression suite. Run real source probes and inspect resulting production publish.
